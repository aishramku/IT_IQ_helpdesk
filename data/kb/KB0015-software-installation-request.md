# Software installation request

How to get Tableau, VS Code, Adobe, Zoom, Power BI or other software installed. This is a Service Request.

## Steps

1. Check Software Centre first - many standard apps install in one click.
2. Otherwise raise a ticket with the software name, version and business reason.
3. Paid software needs manager approval and a licence; installs are never performed without approval.

## Escalation

If the steps above do not fix it, reply to your ticket with what you tried.
