# Slow internet, LAN port or file server unreachable

Symptoms: internet slow, pages not loading, LAN port dead, mapped drive red cross, ERR_NAME_NOT_RESOLVED, HTTP 503.

## Steps

1. Check the cable and the link light on the LAN port; try a different cable.
2. Run ipconfig /flushdns in a command prompt.
3. Re-map the network drive and make sure you are on the corporate network or VPN.
4. Note whether colleagues are affected - that suggests a switch or server issue.

## Escalation

If the steps above do not fix it, reply to your ticket with what you tried.
